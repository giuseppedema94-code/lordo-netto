# lordo-netto

Un calcolatore automatico che permette di calcolare, con precisione, il netto partendo dalla RAL.

**Apri il calcolatore:** https://giuseppedema94-code.github.io/lordo-netto/

- Da lordo a netto e da netto a lordo, regole fiscali 2026 (IRPEF 23-33-43%, cuneo fiscale, trattamento integrativo)
- Minimi dei principali CCNL, fondi pensione e sanitari di categoria già impostati
- Addizionali regionali e comunali dagli elenchi ufficiali del Dipartimento delle Finanze (MEF)
- Cedolino di una busta ordinaria e consigli sulle soglie fiscali

È una stima a scopo informativo, non sostituisce la busta paga.

Il sito è un unico file, `index.html`, pubblicato con GitHub Pages.
